# 🎙️ Google Home Integration

This folder contains the resources and documentation related to Google Home voice control.

## Features

- Voice-based appliance control
- ON/OFF control of connected appliances
- Integration with Sinric Pro
- Hands-free smart home operation

## Example Commands

- "Hey Google, turn on the light."
- "Hey Google, turn off the light."
- "Hey Google, turn on the fan."
- "Hey Google, turn off the fan."

## Control Flow

Google Home → Sinric Pro → ESP8266/ESP32 → Relay → Appliance
