# 📡 Sinric Pro Integration

Sinric Pro provides the IoT communication layer for remote control of connected home appliances.

## Features

- Remote appliance control
- Internet-based communication
- Relay control through ESP8266/ESP32
- Integration with Google Home

## Control Flow

User → Sinric Pro → Internet → ESP8266/ESP32 → Relay → Appliance

## Supported Control

- Light ON/OFF
- Fan ON/OFF
- Other connected appliances
