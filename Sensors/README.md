# 🌡️ Sensors

This folder contains the sensor-related resources used in the IoT-based home automation system.

## Sensors Used

### DHT11
Used for:
- Temperature measurement
- Humidity measurement

### LDR
Used for:
- Light intensity detection
- Automatic light control

## Purpose

Sensor data is processed by the ESP8266/ESP32 and used to automatically control connected appliances based on predefined conditions.
